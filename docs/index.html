Get Started in 3 Steps

Simple setup with zero terminal friction or full developer freedom.

01

Clone the Repository

Download the latest release or clone the source directly from GitHub.

git clone https://github.com/Aiko-AI/Project-Aiko.git
02

Configure Without a Terminal

Double-click SETUP_AIKO.vbs to launch the visual dark-mode configuration wizard.

wscript SETUP_AIKO.vbs
03

Launch Aiko

Double-click LAUNCH_AIKO.vbs to launch Aiko with zero console window popups.

wscript LAUNCH_AIKO.vbs
